# Public-release privacy and ethics checklist

The accompanying EEE 312 Group 04 report says voice recordings and trained models are for course-project use and not for sharing outside the group and instructors. It also says participants may withdraw their recordings. That commitment applies even if this repository is intended solely as a portfolio.

Before publishing publicly:

- [ ] Obtain your teammates' agreement to publish jointly developed source code.
- [ ] **Do not publish** original voice recordings, spectrograms labeled with real identities, or derived speaker-model `.mat` files without specific, informed permission.
- [ ] **Do not publish** authentication logs, real participant IDs, enrollment rosters, or raw biometric templates.
- [ ] Check screenshots, demos, and report PDFs for identifying names, roll numbers, voices, or faces. Link a video only after obtaining suitable permission.
- [ ] Confirm the report authors' consent before publishing the original PDF; it contains identifiable names and student IDs.
- [ ] Audit future commits before pushing; `.gitignore` is a guardrail, not a replacement for reviewing staged files and git history.
- [ ] Consider creating a separate **synthetic or newly consented** demo dataset for reproducibility.

This package includes only MATLAB source code and public-facing descriptions. Two source-code example IDs have been replaced with the fictional placeholder `1234567`; no algorithmic code was intentionally changed.
